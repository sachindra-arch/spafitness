# SPA Fitness

A modern, responsive gym website built with HTML and CSS. SPA Fitness showcases training programs, membership plans, facilities, testimonials, and contact details through a clean and engaging user interface.

## 🎯 Overview

SPA Fitness is designed to represent a premium fitness brand while providing a smooth and accessible user experience. Whether you're a gym owner looking for a professional online presence or exploring modern web design practices, this project delivers a polished, mobile-friendly solution.

## ✨ Features

- **Responsive Design**: Fully optimized for desktop, tablet, and mobile devices
- **Training Programs**: Showcase various fitness programs and classes
- **Membership Plans**: Display flexible membership tiers with pricing and benefits
- **Facilities**: Highlight gym equipment, amenities, and infrastructure
- **Testimonials**: Feature client success stories and reviews
- **Contact Section**: Easy-to-use contact form and location information
- **Clean UI**: Modern, professional design with intuitive navigation
- **Accessible**: Built with accessibility best practices in mind

## 🚀 Getting Started

### Prerequisites

- A modern web browser (Chrome, Firefox, Safari, Edge)
- No server-side dependencies required for static viewing

### Installation

1. **Clone the repository**
   ```bash
   git clone https://github.com/sachindra-arch/spafitness.git
   cd spafitness
   ```

2. **Open in browser**
   - Double-click `index.html` to open locally, or
   - Use a local server for best results:
     ```bash
     python -m http.server 8000
     # Then visit http://localhost:8000
     ```

Visit the live site: [SPA Fitness](https://sachindra-arch.github.io/spafitness)

## 🎨 Customization

### Colors & Branding
Edit the CSS variables in `css/styles.css` to customize:
- Primary color scheme
- Font families
- Spacing and sizing

### Content
Update HTML files to:
- Add your gym's information
- Replace placeholder images with your own
- Modify membership plans and pricing
- Add testimonials from real clients

### Images
Replace placeholder images in the `images/` directory with high-quality photos of your facility.

## 📱 Responsive Breakpoints
